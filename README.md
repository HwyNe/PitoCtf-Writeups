# PitoCtf-Writeups

Bu repo, çözdüğüm CTF (Capture The Flag) sorularına ait writeup'ları daha düzenli ve okunabilir şekilde toplamak için hazırlanmıştır.

## Kategoriler

- Web
- Reverse Engineering
- Crypto
- Forensics
- Mobile
- OSINT
- Steganography
- Misc

## Amaç

Bu depo; çözüm sürecimi arşivlemek, öğrendiklerimi paylaşmak ve benzer sorularla uğraşan kişilere yardımcı olmak için tutulur.

## Düzen

Her writeup mümkün olduğunca şu yapıyı takip eder:

- Challenge adı
- Kategori
- Zorluk
- Kısa açıklama
- Çözüm adımları
- Kullanılan araçlar
- Sonuç / flag
